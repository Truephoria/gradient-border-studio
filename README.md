# Gradient Border Studio

Animated gradient window borders for streams, exported as looping transparent GIFs.

Pick a shape, size, colours and speed, watch the live preview, then hit **Export GIF**.
In OBS: Sources → + → Image → pick the GIF, sized to match the window it frames.

![Example border](example.gif)

Everything runs in your browser; nothing is uploaded anywhere.

Based on the effect from [Animated Gradient Border Generator](https://theowoo.github.io/agbg/) by theowoo,
rebuilt so every frame can be drawn and saved as a GIF.
